# Security policy

## Supported versions

HasadHaber is an early-stage research prototype. Security fixes are applied to
the latest revision on the `main` branch.

## Reporting a vulnerability

Please do not disclose credentials, private field data, or an exploitable issue
in a public GitHub issue. Use GitHub's **Report a vulnerability** option in the
repository Security tab to open a private security advisory.

Include the affected component, reproduction steps, potential impact, and any
suggested mitigation. You should receive an acknowledgement within seven days.
